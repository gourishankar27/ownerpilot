Implemented catalog preview/confirmation/versioning, real Okapi BM25, local Nomic neural embeddings stored in PostgreSQL/pgvector, exact cosine retrieval, RRF, transparent specification reranking and auditable product decisions from approved RFQs. Local functional workflows and synthetic retrieval evaluation operate. Existing extraction defaults and approved RFQs remain unchanged. ## Error analysis

Exact-only intentionally misses no-MPN descriptions. Vector similarity confuses capacities/configuration variants. Plain fusion ranks worse than BM25 on this corpus; deterministic required-spec reranking repairs ordering. Missing specs remain insufficient information. Same MPN/different specs stays ambiguous; different suppliers remain offers. Shared templates and limited authored attributes make this easier than real procurement. Impossible-capacity no-match fixtures do not establish realistic open-world abstention quality. Complex units/OEM compatibility remains unproven.
