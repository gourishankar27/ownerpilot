# Product identity

MPN case, punctuation, zeroes, slashes, underscores, suffixes and O/0 stay significant. Only outer whitespace and Unicode dashes normalize. Manufacturer whitespace/case folds; reviewed fictional alias Northvale Systems→Northvale is version1. Fuzzy names never establish identity.

Identity hashes manufacturer,MPN,category and complete specs. Capacities, voltage, connectors and pack sizes remain distinct. Identical products from different suppliers retain separate offer/source IDs. Conservative32 versus32.0/unit spelling can produce false duplicates; no universal unit equivalence. Semantic similarity never defines identity. Benchmark has204 authored duplicate offers,1020 variants and1224 source listings. No proprietary catalogs or invented authentic commercial SKUs.
