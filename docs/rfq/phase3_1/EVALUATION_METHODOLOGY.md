# Independent research evaluation

The additive `procurement-v2` corpus was frozen before model tuning: 60 native scenarios, 66 line cases, 12 development, 12 validation and 36 held-out. Twenty adversarial fixture descriptors are separate and do not increase the native denominator. The manifest pins SHA-256 `d91fdb00333a2525de14da303cd1a2f9ee0caed7248e80eea7d242b39f3aa9e9`. `scripts/procurement31-freeze.py` imports no agent/calculation code and refuses to overwrite an existing dataset.

Split-specific fictional manufacturers, MPNs and source identities prevent the same product identity crossing splits. Patterns intentionally overlap: missing values, current/expired/future dates, two suppliers, conflicts, supersession, packs/MOQ/breaks, mixed currencies, unknown tax/shipping, identity mismatches, multiple lines and source/catalog/policy injection. Human selections explicitly remain no-match when identity or suitability is unsupported. The corpus is synthetic; a high score cannot establish production readiness.

All variants use the same approved RFQs, reviewed catalog sources, human attestations, quote policies and source bindings. Fixture administration uses signed API calls and explicit synthetic workspace administration. Catalog indexing uses the installed real Nomic model. Actual Ollama chooses the tool calls; the evaluator supplies neither tool answers nor a forced business sequence. It runs the production runner inline while pausing only the isolated validation worker to prevent duplicate consumption.

The comparison consists of the frozen prompt-5 provider/runner, prompt-6 citation-only initial result, prompt-6 plus the bounded correction, and a separately executed deterministic source report. Citation-only without correction is a **paired first-finalization ablation of the same native trace**, not another independent stochastic run. It shares planning and initial inference with the repair variant. Repair-free cases are the same result. No-verifier completion is never an operational API mode.

The evaluator separately checks exact authored values, missing values, selection state, freshness, conflict/supersession, line/product/catalog/offer/fingerprint associations and required tool coverage. Correct-value/wrong-offer facts fail. Required fact coverage is stricter than the historical prompt-5 definition: a legacy `complete` run can fail this new independent research measure. Legacy results are mapped for offline assessment without rewriting the stored historical protocol. Source scope/receipt ownership remain production-verifier responsibilities, with independent adversarial fixtures.

Configuration hashes pin the production provider, resolver, runner, contracts and tool registry plus the actual model digest. Development failures remain in `results/evaluation/dev-contract6`; the same configuration continues through validation and held-out. No held-out labels or source facts were changed to fit results. Label disagreements with the financial engine are recorded, not rewritten.

The original ten-case comparison is separate. Original prompt-5 measurements remain recorded historical observations. Fresh citation-only runs use a migrated **clone** of those exact source identities/attestations, with source fingerprint equality checked before every case. They are not merged with the 60-case corpus. The new held-out quality target is at least 95%; zero unsupported accepted facts and unauthorized effects remain mandatory.

Timing uses observed end-to-end runner time; repair latency and token counts come from actual model-call responses. The paired initial-only latency distribution excludes repaired traces because a separately executed no-repair total is unavailable. Initial checkpoint timestamps include database admission, so they are retained as diagnostics and never mixed with runner-entry latency. Completion still uses the full corpus denominator. P95 uses the nearest-rank order statistic. GPU samples are device-wide before/after values, not peaks or model-isolated VRAM. Loaded-model markers and actual load durations identify warm behavior. No unavailable memory metric is imputed. Inline runs do not yield a Celery queue-wait measurement; actual recovery/browser checks are separate.

The frozen source date is November 22, 2026. Current production freshness is time-dependent; future replay must report the execution date and any changed classifications. Synthetic data/labels remain frozen. Financial evaluation uses a separate rational oracle and never counts schema validity as financial correctness.
